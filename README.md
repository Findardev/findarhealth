# Findar Health

Website: https://findarhealth.com

## Current product
Findar Health is a WordPress-based hospital discovery and navigation platform. Users can search real hospital listings and get directions. The platform has recorded over 5,000 search impressions; this measures visibility, not unique users, referrals or clinical outcomes.

## Proposed UNICEF project
Extend the existing platform to support maternal care navigation and referrals in Lagos, Nigeria. Planned work includes verified maternal service profiles, referral coordination and AI-assisted information retrieval grounded in verified facility records. These capabilities are proposed, not currently implemented. Clinical decisions will remain with qualified healthcare professionals.

## Technical foundation
Theme: Doccure. See PLUGINS.md for the screenshot-based dependency inventory. 

## Contents and limitations
Current implementation and source code
Findar Health’s working prototype was built using WordPress, the Doccure theme and existing plugins. We configured these tools to provide hospital listings, search and directions. No custom application code was developed for the current prototype.

This repository therefore contains product and technical documentation, including a dependency inventory, rather than custom application source code. Third-party software remains subject to its respective licences and is not included in this repository.

The working prototype is available at https://findarhealth.com.
Proposed open-source development
Through the proposed UNICEF-funded project, we intend to develop an open-source maternal care navigation and referral module, including AI-assisted search grounded in verified facility information. These features are planned and are not part of the current prototype. Custom code developed through the project will be published under an appropriate open-source licence, with personal health information excluded.

## Open-source commitment
There is a confirmed willingness to open-source custom technology developed through the proposed grant. No software license is assigned by this documentation package. Third-party code retains its respective licences. 

## Privacy
Do not commit patient records, credentials, API keys, production database exports, private uploads or licence keys.
