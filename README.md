# Findar Health

Website: https://findarhealth.com

## Current product
Findar Health is a WordPress-based hospital discovery and navigation platform. The founder confirms that users can search real hospital listings and get directions. The platform has recorded over 5,000 search impressions; this measures visibility, not unique users, referrals or clinical outcomes.

## Proposed UNICEF project
Extend the existing platform to support maternal care navigation and referrals in Lagos, Nigeria. Planned work includes verified maternal service profiles, referral coordination and AI-assisted information retrieval grounded in verified facility records. These capabilities are proposed, not currently implemented. Clinical decisions will remain with qualified healthcare professionals.
