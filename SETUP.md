# Technical setup

## Current implementation

Findar Health runs on WordPress using the Doccure theme and existing plugins. The prototype was built through configuration of these tools; no custom application code was developed.

The working website supports hospital discovery, search and directions:
https://findarhealth.com

See PLUGINS.md for the recorded plugin inventory.

## Repository scope

This repository documents the existing prototype and proposed development. It is not a standalone installation package.

WordPress, Doccure and the plugins are obtained separately from their respective providers and remain subject to their own licences. Production credentials, database backups and personal information are excluded.

## Reproducing the prototype

Recreating the website would require a compatible WordPress hosting environment, the relevant theme and plugins, page and plugin configuration, hospital listings, and any required map service settings.

A separate installation using this documentation has not been tested.

## Proposed development

The proposed project will add an open-source maternal care navigation and referral module, including AI-assisted search grounded in verified facility information.

Installation instructions and technical requirements for that module will be published alongside its code as it is developed.
